# Social Media App (Flutter)

Features
----------------
* Authentication by email
* Posts
  * Post photo posts from camera or gallery (crop function included)
  * Like posts
  * Comment on posts
  * View all comments on a post
* Search users by username
* Follow/Unfollow users
  * New posts from following users
* Profile
  * View profile
  * Edit profile information: username, bio, profile avatar
* Push notifications on like, comment, follow, unfollow from other users
*  Settings
  * Customize app theme (light/dark)

Key technologies
----------------
* Flutter
* bloc / flutter_bloc / hydrated_bloc
* firestore database
* cloud functions
* firebase auth
* flutter_local_notifications
* image_picker + crop_image
